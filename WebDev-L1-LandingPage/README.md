# Royal Stay – Hotel Landing Page

## Project Overview

Royal Stay is a responsive hotel landing page developed as part of the Web Development & Designing Internship.

The website provides information about the hotel, its facilities, and contact details through a clean and user-friendly design.

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Responsive Design

## Features

* Sticky navigation bar
* Hero section
* Call-to-action button
* Luxury Rooms section
* Fine Dining section
* Swimming Pool section
* About section
* Contact section
* Footer with social links
* Responsive design for desktop and mobile devices

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Run `index.html` using a web browser or Live Server.
4. The Royal Stay landing page will be displayed.
